## 4.19. E50205. (O轴) 无法维持伺服锁定 - 异常电流输出

### 1. 概述

当电机或驱动单元所需的电流未正常施加时会发生此情况。<br>
这可能是由于电机与控制器之间的接线不良，或电流命令和反馈电路的故障引起的。<br>
当控制电机所需的参数（增益、最大电流等）由于机器人模型注册错误而与实际电机规格不匹配时，也可能发生此情况。

### 2. 原因和检查

{% hint style="info" %}

(1) 检查机器人模型是否设置正确。<br>
(2) 检查电机电源线和编码器通信线。<br>
* 检查连接机器人和控制器的接线。
* 检查机器人的内部接线。
* 检查控制器的内部接线。

(3) 检查控制器内部伺服安全板与放大器板之间的电缆或连接器。<br>
(4) 更换其他组件。<br>

{% endhint %}

(1)	检查机器人模型是否设置正确。<br>
检查TP屏幕上注册的机器人模型是否与实际安装的机器人匹配。

![](../_assets/4.서보보드/robot_model.png)<br>
图 4.19.1 机器人模型检查

(2)	检查电机电源和编码器通信线。<br>
关闭控制器电源，断开对应轴驱动单元的U、V、W，并检查每个相位是否短路或开路。使用万用表（测试仪）逐相检查接线。检查编码器通信线是否断开。

---

{% hint style="warning" %}

在通电检查时要小心，以免发生电击风险。

{% endhint %}

---

* 检查连接机器人和控制器的接线。
断开连接控制器和机器人或驱动单元的接线，并检查每个相位（U相、V相、W相）是否彼此短路或接地。如果发现任何短路，必须更换相应的接线。

![](../_assets/4.서보보드/hi7_robot_power_cable.png)<br>
图 4.19.2 N 控制器与机器人之间的接线

* 检查机器人的内部接线。<br>
必须检查连接到机器人内部电动机的接线是否存在短路或接线不当。

![](../_assets/4.서보보드/robot_inner_cable.png)<br>
图 4.19.3 机器人内部接线

* 检查控制器的内部接线。<br>
必须检查控制器内部与放大器安装的接线。

![](../_assets/4.서보보드/hi7_brake_cable.png)<br>
图 4.19.4 N 控制器内部接线检查

(2)	检查控制器内部伺服安全板与放大器板之间的连接器（板对板）。<br>
检查连接和固定伺服安全板与放大器板的连接器（板对板）安装是否正确。如果固定状态不佳，可能会发生此错误。

![](../_assets/4.서보보드/conncet_bd642_amp.png)<br>
图 4.19.5 Hi7-N 控制器伺服板与放大器板之间的连接

(3)	更换其他组件。<br>
按顺序更换组件：伺服安全板（BD642）→ 放大器板 → 接线束 → 电动机 → PSM，以检查错误发生情况。

![](../_assets/4.서보보드/hi7_robot_brake_power_check.png)<br>
图 4.19.6 N 控制器驱动组件
