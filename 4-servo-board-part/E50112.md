## 4.15. E50112. (O 轴) 编码器电池错误

### 1. 概述

伺服安全板与编码器进行串行通信，以控制伺服电机并定期接收编码器数据。<br>
当连接到编码器的电池电压降至标准值以下，或电池连接出现问题时，BE（电池错误）位被设置，从而发生此错误。<br>
即使从编码器本身接收到的数据正常，如果编码器内部状态监测结果判断为错误状态（BE），也可能发生此错误。

**BE（电池错误）**：当外部电池电压降至3.1V或更低，而编码器主电源关闭时被设置。


### 2. 原因与检查

{% hint style="info" %}

(1) 在重置串行编码器错误后，关闭控制器电源，然后再重新打开。<br>
(2) 检查编码器备用电池电压。<br>
(3) 检查编码器电池连接状态。<br>
(4) 执行电机（编码器）更换测试。<br>

{% endhint %}

(1) 在重置串行编码器错误后，关闭控制器电源，然后再重新打开。<br>
如果在重置错误后，主电源关闭/打开时错误仍然存在，请执行电机（编码器）更换测试。
错误重置在以下菜单中执行。

        System -> 5. Initialization -> 4. Serial Encoder Reset - Error Release

![](../_assets/4.서보보드/enc_error_clear.png)<br>
图 4.15.1 编码器错误解除

(2) 检查编码器电池电压。<br>
编码器电池为3.6V。如果此电压降到3.0V~3.2V，则会显示"W0104 o 轴编码器电池电压低"。当发生此警告时，必须更换编码器电池。在此状态下，必须在控制器电源打开时进行编码器电池更换。如果此时用正常的编码器电池进行更换，可以继续正常使用机器人。

如果超过编码器电池更换时间而电压降至2.5V~3.0V，当控制器电源开启时会发生错误"E2470 o 轴编码器异常：需要重置编码器"。如果发生此错误，编码器位置数据已丢失。在更换编码器电池并重置编码器后，必须使用手动操作将机器人移至参考姿势，并为相应轴重新进行编码器校准。

![](../_assets/4.서보보드/battery_replace_position.png)<br>
图 4.15.2 编码器电池更换位置

编码器重置在以下菜单中执行。

        System -> 5. Initialization -> 4. Serial Encoder Reset - Encoder Reset

![](../_assets/4.서보보드/enc_reset.png)<br>
图 4.15.3 编码器重置

(3) 检查编码器电池连接状态。<br>
检查从编码器电池位置连接到电机的电池接线状态。


(4) 执行电机（编码器）更换测试。<br>
如果在重置错误后在主电源关闭/打开时错误仍然存在，请执行电机（编码器）更换测试。如果更换后不再发生错误，则伺服电机故障。请将伺服电机更换为正常单元。下图显示了机器人每个轴的电机位置。对于其他机器人，请参考相应的机械维护手册进行更换。
