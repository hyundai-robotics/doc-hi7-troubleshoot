## 4.5. E50102. (O Axis) 编码器接收数据长度异常

### 1. 概述

伺服安全板与编码器进行串行通信以控制伺服电机，并定期接收编码器数据。<br>
当从编码器接收到的数据长度不符合规定值时，会发生此错误。<br>

接收到的数据长度与编码器不匹配的情况主要发生在由于布线缺陷或编码器屏蔽线处理问题导致噪声进入编码器信号线时。

### 2. 原因及检查

{% hint style="info" %}

(1) 检查编码器布线。<br>
(2) 进行电机（编码器）更换测试。<br>
(3) 进行伺服安全板更换测试。<br>
(4) 在完成措施后检查布线的通信状态。<br>

{% endhint %}

(1) 检查编码器布线。<br>
编码器布线的检查顺序如下。<br>
第1步：检查与编码器布线相关的连接器是否有接触不良。<br>
第2步：检查编码器布线是否有短路。使用万用表（测试仪）1:1检查每相的布线。<br>
第3步：进行编码器布线更换测试。<br>

如果编码器布线没有断开，但存在屏蔽线接触不良或编码器信号线与其他电源线或机器人本体金属部分接触等问题，这些问题无法通过短路检查检测到。因此，进行布线更换测试。

* 检查控制器内部布线。<br>
检查 CNEN13,46 (BD642) 连接器与 CEC1 之间的布线。

* 检查控制器与机器人之间的布线。<br>
对于 Hi7-N 控制器，检查 CEC1 与 CER1 之间的布线。

![](../_assets/4.서보보드/hi7_robot_encoder_cable.png)<br>

* 检查机器人本体的内部布线。<br>
检查 CER1 与编码器侧连接器之间的布线。有关布线检查，请参考机器人维护手册中的布线连接图。

![](../_assets/4.서보보드/robot_inner_cable.png)<br>
图 4.5.4 机器人内部布线

(2) 进行电机（编码器）更换测试。<br>
如果更换伺服电机后错误不再出现，则伺服电机故障。请将伺服电机更换为正常单元。下图显示了机器人每个轴的电机位置。有关其他机器人，请参考相应的机械维护手册进行更换。

![](../_assets/4.서보보드/HS165_motor_position.png)<br>
图 4.5.5 机器人每个轴的电机位置

(3) 进行伺服安全板更换测试。<br>
如果更换伺服安全板后错误不再出现，则伺服安全板故障。请将伺服安全板更换为正常单元。

![](../_assets/4.서보보드/hi7_controller_bd642.png)<br>
图 4.5.6 N 控制器伺服安全板更换

(4) 在完成措施后检查布线的通信状态。<br>
在针对问题部分的措施完成后，请参考 `Encoder Communication Failure Count Display Function Manual` 检查通信状态。
