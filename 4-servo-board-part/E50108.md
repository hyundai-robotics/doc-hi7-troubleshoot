## 4.11. E50108. (O 轴) 编码器计数错误 (检测到 CE 位)

### 1. 概述

伺服安全板通过串行通信与编码器进行伺服电机控制，并定期接收编码器数据。<br>
当编码器内部发生旋转值计算错误并设置 CE（计数错误）位时，就会发生此错误。<br>
即使从编码器本身接收到的数据是正常的，这个错误也可能发生，但编码器内部状态监控结果将其判定为错误状态（CE）。<br>

**CE（计数错误）**：当编码器加电时，由于故障或失效导致单圈数据出现位置不对齐时设置。

### 2. 原因和检查

{% hint style="info" %}

(1) 检查编码器供电电压。<br>
(2) 重置串行编码器错误后，关闭并重新开启控制器电源。<br>
(3) 如果错误持续存在，请进行电机（编码器）更换测试。<br>

{% endhint %}

(1) 检查编码器供电电压。<br>
提供给编码器的电源电压必须在编码器侧连接器范围内的 5.0V±5%（4.75V ~ 5.25V）。如果编码器侧连接器的电压低于 4.75V，编码器将无法正常工作，并且上述错误可能发生。

测量编码器侧连接器引脚的电压（3-4）。

![](../_assets/4.서보보드/encoder_connector_pin_info_en.png)<br>
图 4.11.1 编码器连接器引脚信息

如果测得的电压低于参考电压，请调节伺服安全板（BD642）上的 VR1 可变电阻器，以调整编码器侧连接器电压，使其在参考电压范围内。

![](../_assets/4.서보보드/BD642_encoder_voltage_adjustment.png)<br>
图 4.11.2 BD642 编码器电压可变电阻

(2) 重置串行编码器错误后，关闭并重新开启控制器电源。<br>
如果在重置错误后主电源 OFF/ON 时错误仍然存在，请进行电机（编码器）更换测试。
错误重置在以下菜单中进行。

        System -> 5. Initialization -> 4. Serial Encoder Reset - Error Release

![](../_assets/4.서보보드/enc_error_clear.png)<br>
图 4.11.3 串行编码器错误释放

(3) 如果错误持续存在，请进行电机（编码器）更换测试。<br>
如果更换伺服电机后没有发生错误，则伺服电机存在故障。请用正常的单元更换伺服电机。下图显示了机器人每个轴电机的位置。对于其他机器人，请参阅相应的机械维护手册进行更换。
