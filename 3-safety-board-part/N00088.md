## 3.1. N00088 外部紧急停止（E-Stop）输入

### 1. 概述
外部紧急停止（E-Stop）信号已被触发。<br>
为了确保安全，所有机器人运动立即停止，伺服电机切换至 **Motor OFF** 状态。

### 2. 原因与检查
{% hint style="info" %}
(1) 外部紧急停止（E-Stop）按钮确实被按下。<br>
(2) 外部 E-Stop 电路的接线或接触处存在问题。<br>
(3) 外部 E-Stop 信号的安全输入分配未配置。<br>
{% endhint %}<br>

### (1) 当外部 E-Stop 按钮确实被按下时
检查外部紧急停止（E-Stop）按钮是否确实被按下。可能是其他操作员或管理员触发了 E-Stop 按钮。<br>
此外，请确认机器人周围是否有人员或安全围栏内的潜在危险（工具、夹具等），因为可能有人在工作。<br>
如果判断安全，可以重新启动机器人，首先解除外部 E-Stop 按钮，之后在 **Manual Mode** 下操作机器人，然后再恢复正常操作。<br>

### (2) 当外部 E-Stop 电路的接线或接触处存在问题时
要检查外部 E-Stop 相关的接线，首先通过 **Safety I/O Assignment** 功能检查外部 E-Stop 信号分配到哪个输入通道。<br>
默认情况下（出厂设置），外部 E-Stop 输入分配给基本安全输入。

System -> 8: Safety System -> 2: Parameter Settings -> 3: Safety I/O -> 1: I/O Assignment<br>

#### 2-1) 当分配给基本安全输入时
如果外部 E-Stop 输入分配给 **Basic Safety Input**，它连接到伺服安全板上的 **CNSI1 连接器（4 通道）**。有关该连接器的详细引脚映射，请参考 **Hi7 Controller Maintenance Manual, Section 4.3.2.6**。

![](../_assets/3-Safety-io/N00088/bd642_cnsi1_position.png)<br>
图 3.1.2. Hi7-N 控制器伺服安全板 CNSI1 位置<br>

检查外部 E-Stop 输入分配到哪个通道。输入通道分配可以使用图 3.1.1 确认。<br>
确认分配的输入通道后，请参考现场电气图或接线图以确保接线正确。同时检查实际接线以确保连接和组装妥当。<br>
在验证电气图或接线图时，参考 **Hi7 Controller Maintenance Manual, Section 4.3.2.6** 以获取伺服安全板 CNSI1 的标准接线。

#### 2-2) 如果分配给扩展安全输入  
如果外部 E-Stop 输入分配给扩展安全输入，它连接到选项安全 IO 板 CNSI2 连接器（8 通道）。有关该连接器的详细引脚图，请参考 **Hi7 Controller Maintenance Manual, Section 5.4.6**。  
![](../_assets/3-Safety-io/N00088/bd680_cnsi2_position.png)<br>
图 3.1.3. Hi7-N 控制器选项安全 IO 板 CNSI2 位置<br>

检查外部 E-Stop 输入分配到哪个通道。输入通道分配可以使用图 3.1.1 确认。<br>
确认分配的输入通道后，请参考现场电气图或接线图以确保接线正确。同时检查实际接线以确保连接和组装妥当。<br>
在验证电气图或接线图时，参考 **Hi7 Controller Maintenance Manual, Section 5.4.6** 以获取选项安全 IO 板 CNSI2 的标准接线。

#### 2-3) 当分配给安全通信输入时
如果外部 E-Stop 输入分配给安全通信输入，请参考 **Hi7 Robot Controller Function Manual - Industrial Communication**。

### (3) 当外部 E-Stop 信号未设置安全输入分配时
如果在安全输入分配中未选择外部 E-Stop 输入，请通过选择以下选项之一来激活外部 E-Stop 功能：<br>

- 基本安全输入<br>
- 扩展安全输入<br>
- 安全通信输入<br>

安全输入分配可以通过以下菜单配置：

System -> 8: Safety System -> 2: Parameter Settings -> 3: Safety IO -> 1: Input/Output Assignment<br>
