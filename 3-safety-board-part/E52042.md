## 3.6. E52042 (0 ch) 安全输入信号不匹配

{% hint style="warning" %}
检查安全输入接线时，始终确保控制器电源为 **OFF** 以便进行检测。
{% endhint %}

### 1. 概述

检测到基本安全输入通道上的冗余安全输入信号之间存在不匹配。  
为了确保安全，受影响的输入信号被视为 **Fail-Safe (Open or 0)**。

### 2. 原因和检查

{% hint style="info" %}
(1) 由于接线错误或断开造成的信号差异  
(2) 由端子块或电缆条件引起的噪声  
(3) 不正确的安全信号参数（滤波设置、允许的不匹配时间）
{% endhint %}

### (1) 由于接线错误或断开造成的信号差异

安全输入信号不匹配表示连接到伺服安全板 CNSI1 连接器（总共 4 个通道）的安全输入信号之间存在差异。  
有关此连接器的详细引脚映射，请参考 **Hi7 控制器维护手册，第 4.3.2.6 节**。

![](../_assets/3-Safety-io/E52042/bd642_cnsi1_position.png)<br>
图 3.6.1. Hi7-N 控制器伺服安全板 CNSI1 位置

1) 当安全输入信号未使用  
如果错误发生在未使用的通道上，请验证外部接线是否如下面所示。同时检查连接器和电线是否正确组装并良好接触。

![](../_assets/3-Safety-io/E52042/bd642_cnsi1_notused.png)<br>
图 3.6.2. 未使用的伺服安全板 CNSI1 通道接线图
<br>

2) 当安全输入信号正在使用  
如果错误发生在正在使用的通道上，首先检查信号分配给哪个输入通道。可以通过以下菜单验证输入通道分配：

<br>
系统 -> 8: 安全系统 -> 2: 参数设置 -> 3: 安全 IO -> 1: 输入/输出分配

![](../_assets/3-Safety-io/E52042/io_alloc_param1.png)<br>
图 3.6.3. T/P 屏幕 - 安全输入分配

一旦确认输入通道分配，请参考现场电气原理图或接线图以确保正确接线。同时，检查实际接线以确认连接和组装是否正确。  
有关伺服安全板 CNSI1 的接线标准，请参考 **Hi7 控制器维护手册，第 4.3.2.6 节**。

### (2) 由端子块或电缆条件引起的噪声

#### 安全输入信号监测功能  
T/P 上提供安全输入信号的监测屏幕。它可以以 0.5 秒的间隔进行监测，以进行基本验证。

系统 -> 8: 安全系统 -> 3: 监测 -> 3: 安全 IO 状态  
![](../_assets/3-Safety-io/E52042/safety_io_status.png)<br>
图 3.6.4. T/P 屏幕 - 安全 IO 监测

### (3) 安全信号参数设置错误（滤波，不匹配允许时间）

如果安全输入信号的滤波时间过短，或允许的不匹配时间设置过短，可能会频繁发生安全输入信号不匹配警报。  
安全输入信号的推荐默认设置如下。这些值可以根据现场环境和应用条件进行调整。

- 滤波时间：100 (msec)  
- 允许不匹配时间：1000 (msec)
