## 3.2. E00002 主要轴限位开关已激活

### 1. 概述

安装在每个机器人轴行程范围末端的限位开关已被触发。出于安全考虑，机器人立即停止，并且在使用正确的程序将其移回安全操作范围之前，无法正常操作。

### 2. 原因及检查

{% hint style="info" %}
(1) 验证机器人是否确实移动到了操作范围之外。<br>
* 超出操作范围的恢复程序<br>

(2) 如果在没有超出操作范围的情况下仍然发生错误<br>
* 检查系统板连接器（CNLS）<br>
* 检查线束（C(M)ER1或C(M)EC1）<br>
* 检查限位开关和主体内部接线<br>
* 检查安全板（BD632）<br>

(3) 如果主要轴限位开关电路的接线或触点存在异常<br>

(4) 如果未配置主要轴限位开关的安全输入分配<br>
{% endhint %}

### (1) 验证机器人是否确实超出了操作范围

检查机器人是否移出了指定的操作范围。如果同时发生软限位错误，则机器人的确已经超出了操作范围。请使用正确的操作程序将机器人移回操作范围。操作范围因机器人型号而异，因此限位开关的安装位置可能也会不同。请参阅各自机器人的维护手册中的“操作范围限制”部分。

#### [超出操作范围的恢复程序]

在硬件限位开关触发时移动机器人，请遵循以下条件和顺序：

A) 从 **手动模式** 进入 **系统模式**。  
B) 按住教导挂件上的 **启用开关**。  

`手动模式` - `系统 (System)` - `TP 启用开关打开`  

C) 在这种状态下打开 **电机**。  
D) 使用 **移动键** 将机器人移回操作范围。

### (2) 在未超出操作范围的情况下仍然发生错误

首先检查教导挂件上的专用输入信号窗口，查看 **限位（超行程）** 项是否持续处于活动状态。可以通过选择 `窗口布局` - `选择 (Select)` - `系统输入` 来查看该窗口。如果 **限位（超行程）** 项以黄色高亮显示，则表示发生错误。

### [注意]
- 在 **手动模式** 下，教导挂件上的 **启用开关** 必须打开以进行监控。  
- 在 **自动模式** 下，监控会无视启用开关状态。

![](../_assets/3-Safety-io/E00002/그림3.png)<br>
图3.2.3. 系统输入窗口中的超行程监控

在这种情况下，原因可以追溯到与限位开关相关的组件。限位开关通过 **CEC1 - CER1** 电缆与控制器的伺服安全系统相连，如下图所示。

![](../_assets/3-Safety-io/E00002/hw_limit_sw_wire_0_en.png)<br>
图3.2.4. 硬件限位开关接线结构

主要检查点和顺序如下：  
A1) 伺服安全板（CNSI1） **或**  
A2) 选配安全 IO 板（CNSI2）  
B) 控制器的内部接线和连接器  
C) 线束和连接器  
D) 限位开关和机器人主体接线  

在适当位置，跳线限位开关的输入线路，检查监控窗口中的 **限位（超行程）** 项是否变为白色。  
按照以下顺序进行。

### [如何从伺服安全板连接器（CNSI1）或选配安全 IO 板连接器（CNSI2）进行检查]

{% hint style="warning" %}
在 **控制器断电** 的情况下，始终执行电缆的连接或断开。电气危险可能导致人身伤害或财产损失。<br>
{% endhint %}

#### * 如何检查伺服安全板连接器（CNSI1）
此步骤确定故障是否通过 CNSI1 连接器源于伺服安全板。跳线与分配输入通道相关的引脚。然后，在专用输入信号监控窗口中检查 **限位（超行程）** 项。

1. 如果指示灯变为 **白色**，则伺服安全板存在故障。请更换该板。
2. 如果保持 **黄色**（错误状态），请检查从伺服安全板到机器人上硬件限位开关的路径中是否存在故障。

下图显示限位开关分配到通道 1 时跳线短路的示例。通过连接跳线到实际分配的通道来进行测试。

![](../_assets/3-Safety-io/E00002/bd642_cnsi1_short.png)<br>
图3.2.5. 伺服安全板连接器（CNSI1）

#### * 如何检查选配安全 IO 板连接器（CNSI2）
此步骤确定故障是否通过 CNSI2 连接器源于选配安全 IO 板。跳线与分配输入通道相关的引脚。然后，在专用输入信号监控窗口中检查 **限位（超行程）** 项。

1. 如果指示灯变为 **白色**，则选配安全 IO 板存在故障。请更换该板。
2. 如果保持 **黄色**（错误状态），请检查从选配安全 IO 板到机器人上的硬件限位开关的路径中是否存在故障。

下图显示限位开关分配到通道 3 时跳线短路的示例。通过连接跳线到实际分配的通道以进行测试。

### [如何检查线束（C(M)ER1 或 C(M)EC1）]

{% hint style="warning" %}<br>
在连接或断开电缆之前，请始终先关闭控制器电源。电气危险可能导致人身伤害或财产损失。<br>
{% endhint %}

此步骤确定故障是否通过 C(M)ER1 或 C(M)EC1 连接器源于线束。首先，从控制器中拔出 C(M)EC1 线束。然后，在连接到控制器的 C(M)EC1 连接器上跳线与限位开关相关的引脚。检查专用输入信号监控窗口中的 **限位（超行程）** 项以验证信号。

① 如果颜色变为 **白色**，  
故障位于控制器内部 C(M)EC1 连接器与系统板之间的电缆或连接器中。根据需要检查或更换电缆/连接器。  

② 如果颜色保持 **黄色**，  
检查从 C(M)EC1 连接器到机器人上硬件限位开关的区域是否存在故障。  

重新连接 C(M)EC1 线束，并从机器人本体上拔出 C(M)ER1 线束。然后，在 C(M)ER1 线束的连接器上跳线与限位开关相关的引脚。  
检查专用输入信号监控窗口中的 **限位（超行程）** 项。  

① 如果颜色变为 **白色**，  
故障位于 C(M)ER1 和 C(M)EC1 连接器之间的线束电缆或连接器中。根据需要进行检查或更换。  

② 如果颜色保持 **黄色**，  
检查从机器人本体上的 C(M)ER1 连接器到限位开关的区域是否存在故障。

### [如何检查限位开关（SW）和机器人主体内部接线]

{% hint style="warning" %}<br>
在连接或断开任何电缆之前，请始终确保控制器电源 **关闭**。电气危险可能导致人身伤害或财产损失。<br>
{% endhint %}

在将 CER1 线束从机器人本体上断开后，使用万用表对 CER1 连接器上与限位开关相关的线路进行连续性测试。

① 如果电阻测得为 **开路**，  
则限位开关或限位开关与 CER1 之间的连接器/电缆存在故障。根据需要检查或更换。  

② 如果电阻测得为 **短路**，  
请检查其他部分是否存在故障。联系制造商以获取进一步指导。

### (3) 如果主要轴限位开关电路接线或触点存在故障

要检查主要轴限位开关接线，请首先通过 **安全 I/O 分配** 功能检查主要轴限位开关分配到哪个输入通道。  
默认情况下，主要轴限位开关是 **禁用** 的，因此不需要检查。  
如需使用，可以通过选择以下选项之一来通过 **安全 I/O 分配** 功能进行分配：1）基本安全、2）附加安全或3）安全通信。

#### 3-1) 分配给基本安全输入

如果主要轴限位开关输入分配给 **基本安全输入**，则连接到 **伺服安全板上的 CNSI1 连接器（4 个通道）**。  
检查在 CNSI1 连接器上分配的是哪个通道，如第（1）项所述。有关该连接器的详细引脚映射，请参阅《Hi7 控制器维护手册》第 4.3.2.6 节。

#### 3-2) 分配给附加安全输入

如果主要轴限位开关输入分配给 **附加安全输入**，则连接到 **选配安全 I/O 板上的 CNSI2 连接器（8 个通道）**。  
检查在 CNSI2 连接器上分配的是哪个通道，如第（1）项所述。有关该连接器的详细引脚映射，请参阅《Hi7 控制器维护手册》第 5.4.6 节。

#### 3-3) 分配给安全通信输入

如果主要轴限位开关输入分配给 **安全通信输入**，请参考《Hi7 机器人控制器功能手册 - 工业通信》以获取详细信息。

### (4) 如果未配置主要轴限位开关安全输入分配

如果在安全输入分配中未选择外部急停输入，请通过选择以下选项之一激活外部 E-Stop 功能：

- **基本安全输入**  
- **扩展安全输入**  
- **安全通信输入**  

安全输入分配可以通过以下菜单进行配置：

`系统 -> 8: 安全系统 -> 2: 参数设置 -> 3: 安全 I/O -> 1: 输入/输出分配`
