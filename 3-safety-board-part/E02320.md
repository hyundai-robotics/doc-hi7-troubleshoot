## 3.4. E02320 一般安全保护开关已激活

### 1. 概述
已收到一般安全保护信号。<br>
为确保安全，所有机器人运动将立即停止，并且伺服电机将切换到电机关闭状态。

### 2. 原因与检查
{% hint style="info" %}<br>
(1) 一般安全保护信号实际被触发。<br>
(2) 一般安全保护电路的接线或接触异常。<br>
(3) 一般安全保护信号尚未分配给安全输入。<br>
{% endhint %}

### (1) 如果一般安全保护信号实际被触发
检查一般安全保护(SGG)开关是否被实际激活。其他操作员或经理可能触发了一般安全保护(SGG)开关。<br>
此外，由于可能在安全围栏内有人工作，请检查是否有任何人员靠近机器人或是否有潜在危险（工具、夹具等）。<br>
如果判断重新启动机器人是安全的，请释放外部紧急停止按钮，首先以手动模式操作机器人。

### (2) 如果一般安全保护电路的接线或接触存在异常
要检查与一般安全保护相关的接线，请首先使用[安全 I/O 分配]功能检查一般安全保护信号分配到哪个输入通道。<br>
默认情况下，一般安全保护输入分配给基本安全输入。

系统 -> 8: 安全系统 -> 2: 参数设置 -> 3: 安全 I/O -> 1: 安全 I/O 分配<br>
![](../_assets/3-Safety-io/N00088/base_add_comm_si_func_sel.png)<br>
图3.4.1. T/P屏幕 - 安全 I/O 分配

#### 2-1) 如果分配给基本安全输入
如果一般安全保护(SGG)开关输入分配给基本安全输入，则它连接到伺服安全板CNSI1连接器（4个通道）。有关此连接器的详细引脚图，请参阅Hi7控制器维护手册的第4.3.2.6节。

![](../_assets/3-Safety-io/E02320/bd642_cnsi1_position.png)<br>
图3.4.2. Hi7-N 控制器 - 伺服安全板CNSI1位置

检查一般安全保护(SGG)开关输入分配到哪个通道。输入通道分配可以在上面显示的安全 I/O 分配的T/P屏幕中确认。

确认分配的输入通道后，请参考现场的电气原理图或接线图以验证正确的接线。此外，实际检查接线以确保正确连接和组装。

在检查电气原理图或接线图时，请参考Hi7控制器维护手册的第4.3.2.6节以了解伺服安全板CNSI1的接线标准。

#### 2-2) 当分配给扩展安全输入时

如果一般安全保护(SGG)开关输入分配给扩展安全输入，则它连接到选项安全 I/O 板CNSI2连接器（8个通道）。有关此连接器的详细引脚图，请参阅Hi7控制器维护手册的第5.4.6节。

![](../_assets/3-Safety-io/E02320/bd680_cnsi2_position.png)<br>
图3.4.3. Hi7-N 控制器 - 选项安全 I/O 板CNSI2位置

检查一般安全保护(SGG)开关输入分配到哪个通道。输入通道分配可以在上面显示的安全 I/O 分配的T/P屏幕中确认。

确认分配的输入通道后，请参考现场的电气原理图或接线图以验证正确的接线。此外，实际检查接线以确保正确连接和组装。

在检查电气原理图或接线图时，请参考Hi7控制器维护手册的第5.4.6节以了解选项安全 I/O 板CNSI2的接线标准。

#### 2-3) 当分配给安全通信输入时
如果外部紧急停止输入分配给安全通信输入，请参阅《Hi7机器人控制器功能手册-工业通信》以获取详细信息。

### (3) 当未配置一般安全保护信号的安全输入分配时
如果未在安全输入分配中选择一般安全保护输入，请通过选择以下选项之一来激活一般安全保护功能：<br>
- 基本安全输入  
- 扩展安全输入  
- 安全通信输入<br>

安全输入分配可以通过以下菜单进行配置：<br>

系统 -> 8: 安全系统 -> 2: 参数设置 -> 3: 安全 I/O -> 1: I/O 分配<br>
