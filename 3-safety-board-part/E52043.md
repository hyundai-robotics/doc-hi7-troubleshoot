## 3.7. E52043 (0 ch) 额外安全输入信号不匹配

{% hint style="warning" %}
在检查额外安全输入的接线时，请确保控制器电源处于**关闭**状态，然后再进行任何验证工作。
{% endhint %}

### 1. 概述

检测到额外安全输入通道的冗余信号之间存在不匹配。  
为确保安全，受影响的输入信号被视为**故障安全状态（打开或0）**。

### 2. 原因和检查

{% hint style="info" %}
(1) 由于接线错误或断开引起的信号差异  
(2) 由于接线端子或电缆条件引起的噪声  
(3) 安全信号参数设置错误（滤波器，允许不匹配时间）
{% endhint %}

### (1) 由于接线错误或断开引起的信号差异

额外安全输入信号不匹配表示连接到选项安全 IO 板 CNSI2 连接器的额外安全输入信号之间存在差异（共 8 个通道）。  
有关此连接器的详细针脚分配，请参阅**Hi7 控制器维护手册，第 5.4.6 节**。

![](../_assets/3-Safety-io/E52043/bd680_cnsi2_position.png)<br>
**图 3.7.1. Hi7-N 控制器选项安全 IO 板 CNSI2 位置**

1) 使用额外安全输入信号时  
如果错误发生在正在使用的通道上，请验证信号分配到哪个输入通道。可以通过以下菜单检查额外安全输入通道的分配：

系统 -> 8: 安全系统 -> 2: 参数设置 -> 3: 安全 IO -> 1: 输入/输出分配 -> 额外输入 <br>

![](../_assets/3-Safety-io/E52043/add_si_func_sel.png)<br>
**图 3.7.2. T/P 屏幕 - 额外安全输入/输出分配**

确认额外安全输入通道分配后，请参考现场的电气原理图或接线图，以验证实际接线是否与设计相符。  
另外，检查物理接线是否连接正确，组装状态是否正常。  

在验证电气原理图或接线图时，遵循**Hi7 控制器维护手册，第 5.4.6 节**中规定的选项安全 IO 板 CNSI2 的接线标准。

### (2) 由于接线端子或电缆条件引起的噪声

#### 额外安全输入信号的监控功能
在 T/P 提供了额外安全输入信号的监控屏幕。  
监控每 0.5 秒进行一次，允许进行基本验证。

**导航：**  
`系统 -> 8: 安全系统 -> 3: 监控 -> 3: 安全 IO 状态`  

![](../_assets/3-Safety-io/E52043/add_si_monitoring.png)<br>
**图 3.7.3. T/P 屏幕 - 安全 IO 监控**

### (3) 安全信号参数设置不正确（滤波器，不匹配允许时间）

如果额外安全输入信号的滤波时间设置得过短或不匹配允许时间过短，可能会频繁发生额外安全输入信号不匹配的报警。  

额外安全输入信号的推荐默认设置如下。这些数值可以根据现场条件和应用需求进行调整：

- **滤波时间：** 100（毫秒）  
- **不匹配允许时间：** 1000（毫秒）

`系统 -> 8: 安全系统 -> 2: 参数设置 -> 3: 安全 IO -> 3: 额外 IO`
