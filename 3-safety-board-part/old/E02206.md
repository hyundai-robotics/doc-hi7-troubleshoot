# E02206. 主体限制开关断线或未连接

## 1. 概述

尽管机器人没有超出软限制区域，但安装在机器人各轴运动区域末端的限制开关被报告为动作。这是异常情况，因此需要检查限制开关的布线。

## 2. 原因及检查方法

{% hint style="info" %}

在未超过软限制的情况下，检测到硬件限制开关动作的异常情况。

请检查开关或布线系统是否存在问题。

{% endhint %}

E02206 主体限制开关断线或未连接发生

在未超过软限制的情况下，检测到硬件限制开关动作的异常情况。请检查开关或布线系统是否存在问题。

* 硬件限制开关故障：开关损坏或因某种原因处于打开状态。
* 布线：布线断裂或受损导致接触不良。
* 连接器：连接器脱落或受损导致连接不良等断线问题。

详细的检查要点请参见“硬件限制开关检查方法”章节。
