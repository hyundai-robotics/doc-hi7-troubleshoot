# E02206. 本体限位SW断线或未连接

## 1. 概述

尽管机器人没有超出软限位区域，但安装在机器人各轴动作区域末端的限位开关仍然被记录为触发。这是异常情况，因此必须检查限位SW的接线。

## 2. 原因及检查方法

{% hint style="info" %}

在没有超过软限位的情况下检测到硬件限位开关触发的异常情况。

由于开关或接线系统存在问题，请进行检查。

{% endhint %}

E02206 本体限位SW断线或未连接发生

在没有超过软限位的情况下检测到硬件限位SW触发的异常情况。由于开关或接线系统存在问题，请进行检查。

* 硬件限位SW故障：开关损坏或因任何原因处于开放状态(Open)。
* 接线：接线断裂或受损，导致接触不良。
* 连接器：连接器脱落或受损导致连接不良等断线问题。

详细检查要点请参见“硬件限位开关检查方法”项。
