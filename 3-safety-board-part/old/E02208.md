# E02208. 本体限制SW输入不一致 (安全链 2 OFF)

## 1. 概述

尽管机器人没有超出软限制区域，但安装在机器人每个轴的运动区域末尾的限制SW却被触发为输入状态。然而，由于安全链 1 的输入与安全链 2 的输入状态不同，因此需要进行检查。

## 2. 原因及检查方法

{% hint style="info" %}

在没有超出软限制的情况下，检测到硬件限制SW工作的不正常情况。

由于开关或布线系统存在问题，请进行检查。

{% endhint %}

图 1 E02208 本体限制SW输入不一致（安全链 2 OFF）发生

在没有超出软限制的情况下，检测到硬件限制SW工作的不正常情况。安全链 2 开放(open)时出现了问题。请检查相关的开关或布线系统。

* 硬件限制开关故障：开关损坏或因其他原因开放(open)。
* 布线：布线断裂或受损导致接触不良。
* 连接器：连接器脱落或受损导致接触不良等断线问题。

详细的检查要点请参阅“硬件限制开关检查方法”章节。
