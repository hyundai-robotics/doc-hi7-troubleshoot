# E02208. 本体限制SW输入不一致（安全链2 OFF）

## 1. 概述

尽管机器人没有超出软限制区域，但安装在机器人各轴动作区域末端的限制SW被输入为已动作。然而，由于安全链1的输入和安全链2的输入状态不同，因此需要进行检查。

## 2. 原因及检查方法

{% hint style="info" %}

在未超过软限制的情况下检测到硬件限制SW动作的异常情况。

请检查开关或布线系统是否存在问题。

{% endhint %}

图1 E02208 本体限制SW输入不一致（安全链2 OFF）发生

在未超过软限制的情况下检测到硬件限制SW动作的异常情况。安全链2处于开放状态，导致问题发生。请检查相关的开关或布线系统。

* 硬件限制开关故障：开关损坏或因任何原因而开放。
* 布线：布线断裂或损坏导致接触不良。
* 连接器：连接器脱落或损坏导致接触不良等断线问题发生。

详细检查要点请参阅“硬件限制开关检查方法”项。
