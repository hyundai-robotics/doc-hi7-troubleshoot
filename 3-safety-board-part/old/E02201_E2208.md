# E02001 ~ E02208 硬件极限SW检查方法

## 1. 原因及检查方法

当硬件极限异常作动时，请参照以下方法进行检查。

### (1) 开关状态监控

硬件极限输入状态可以通过教学手柄的专用输入信号窗口确认。
选择“『窗口设置』→『选择』→『系统输入』”即可查看。如果极限（Over-Travel）项显示为黄色，表示硬件极限SW已启动（open），即机器人已脱离硬件操作区域。

* 注意：
在手动模式下必须打开教学手柄的启用开关才能进行监控。在自动模式下，无论启用开关状态如何，都将进行监控。

### (3) 硬件极限开关检查方法

#### [通过系统板连接器(CNLS)检查的方法]

{% hint style="warning" %}

警告(Warning)<br>
在连接和拆卸电缆时，一定要确保控制器电源已关闭。电气风险可能导致人身伤害和财产损失。

{% endhint %}

通过系统板的CNLS连接器来判断板是否损坏。请如下面的图所示，通过CNLS连接器短接与极限SW输入相关的引脚。在此状态下，通过专用输入信号监控窗口确认极限（Over-Travel）项。

① 如果变为白色，则表示系统板损坏。请更换板。<br>
② 如果仍然是黄色错误状态，请检查系统板之后到本体极限开关之间的区域是否有故障。<br>

#### [通过线束(C(M)ER1或C(M)EC1)检查的方法]

{% hint style="warning" %}

警告(Warning)<br>
在连接和拆卸电缆时，一定要确保控制器电源已关闭。电气风险可能导致人身伤害和财产损失。

{% endhint %}

通过线束连接器C(M)ER1或C(M)EC1判断电缆是否损坏。首先从控制器上拆下C(M)EC1线束，然后在附着在控制器上的C(M)EC1连接器中短接与极限SW相关的引脚。在此状态下，通过专用输入信号监控窗口确认极限（Over-Travel）项。

① 如果变为白色，<br>
则控制器内部的C(M)EC1连接器与系统板之间的电缆或连接器损坏。请检查或更换。

② 如果仍然是黄色错误状态，<br>
请检查C(M)EC1连接器之后到本体极限开关之间的区域是否有故障。

#### [检查极限SW和本体内部接线的方法]

从本体上拆下C(M)ER1线束后，使用万用表对本体的C(M)ER1连接器中与极限SW相关的线路进行短路测试。

① 如果测得电阻为开路状态，<br>
则为极限SW或极限SW-CER1之间的连接器或连接器损坏。请检查或更换。

② 如果测得电阻为短路状态，<br>
则需检查其他部分是否损坏。请与我们联系。
