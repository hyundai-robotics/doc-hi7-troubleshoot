# E02001 ~ E02208 硬件限位开关检查方法

## 1. 原因及检查方法

为检查硬件限位异常情况，请参考以下方法。

### (1) 开关状态监测

硬件限位输入状态可以通过教学操纵杆的专用输入信号窗口确认。
选择“『窗口设置』→『选择』→『系统输入』”可以查看。限位（Over-Travel）项目如果显示为黄色，则表示硬件限位开关已操作（open），即机器人已超出硬件操作区域。

* 注意：
在手动模式下，需要将教学操纵杆的启用开关打开才能进行监测。在自动模式下，与启用开关状态无关，均会进行监测。

### (3) 硬件限位开关检查方法

#### [通过系统板连接器（CNLS）进行检查的方法]

{% hint style="warning" %}

警告（Warning）<br>
在连接和拆卸电缆时，务必在控制器电源关闭状态下进行。电气危险可能导致人身和财产事故。

{% endhint %}


通过系统板的 CNLS 连接器判断板的故障。请按照下图，通过 CNLS 连接器将与限位开关输入相关的引脚短接。在此状态下，通过专用输入信号监测窗口确认限位（Over-Travel）项目。

① 如果变为白色，则表示系统板故障。请更换板。<br>
② 如果仍显示为黄色错误状态，则需检查系统板后本体限位开关之间的区域故障。<br>

#### [通过线束（C(M)ER1 或 C(M)EC1）进行检查的方法]


{% hint style="warning" %}

警告（Warning）<br>
在连接和拆卸电缆时，务必在控制器电源关闭状态下进行。电气危险可能导致人身和财产事故。

{% endhint %}
 

通过线束连接器 C(M)ER1 或 C(M)EC1 判断电缆故障。首先从控制器的 C(M)EC1 线束拆下电缆，然后在附着于控制器的 C(M)EC1 连接器处短接与限位开关相关的引脚。在此状态下，通过专用输入信号监测窗口确认限位（Over-Travel）项目。

① 如果变为白色，<br>
则表示控制器内部的 C(M)EC1 连接器 – 系统板之间的电缆或连接器故障。请对此进行检查或更换。

② 如果仍显示为黄色错误状态，<br>
需检查 C(M)EC1 连接器后本体限位开关之间的区域故障。

#### [检查限位开关及本体内部接线的方法]

在拆下本体的 C(M)ER1 线束后，使用万用表在本体的 C(M)ER1 连接器处对限位开关相关线路进行短接测试。

① 如果电阻测量为开路状态，<br>
则表示限位开关或限位开关-CER1 之间的连接器或连接器故障。
请对此进行检查或更换。

② 如果电阻测量为短路状态，<br>
则需检查其他部分的故障。请与我公司联系。
