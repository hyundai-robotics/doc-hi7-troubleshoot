# E00002. 硬件限位开关正在工作

## 1. 概述

机器人各轴的运动区域末端安装的限位开关已被触发。为确保安全，机器人会立即停止，直到以适当的方法移动到安全的运动区域之前，无法正常运行。

## 2. 原因及检查

{% hint style="info" %}

(1) 请确认是否确实脱离了运动区域。
* 脱离运动区域的恢复方法

(2) 如果并未脱离运动区域，但仍发生错误
* 在系统板连接器(CNLS)上检查的方法
* 在线束(C(M)ER1或C(M)EC1)上检查的方法
* 检查限位开关及本体内部布线的方法
* 检查安全板(BD632)的方法

{% endhint %}

(1) 请确认是否确实脱离了运动区域。

请确认机器人是否确实超出了运动区域。如果同时发生了软限制错误，则机器人已脱离运动区域。请以适当的操作将机器人移动回运动区域。运动区域因机器人型号而异。因此，限位开关的安装位置也可能不同，请参考该机器人的维修手册中“运动范围限制”部分。

### [脱离运动区域的恢复方法]

在硬件限位开关被触发的情况下，移动机器人需要满足以下条件和顺序进行操作。

A) 从手动模式进入系统模式。 <br>
B) 在示教 Pendant 上按住使能开关。<br>

『手动模式』+ 『系统』+ 『TP 的使能开关 ON』

C) 在此状态下打开电机。<br>
D) 使用手轮将机器人移动回运动区域内。<br>

(2) 如果并未脱离运动区域，但仍发生错误

首先在示教 Pendant 的专用输入信号窗口中确认限位(Over-Travel)项目是否持续输入。您可以通过选择“『窗口设置』→『选择』→『系统输入』”来查看此窗口。如果限位(Over-Travel)项目显示为黄色，则表示发生错误。

### [注意]
在手动模式下，必须将示教 Pendant 的使能开关打开才能进行监控。在自动模式下，无论使能开关状态如何，都会进行监控。

主要检查点和顺序为 

A) 系统板<br>
B) 控制器内部的布线和连接器<br>
C) 线束及连接器<br>
D) 限位开关及本体布线<br>

应在适当位置对限位开关的输入线进行跳接，以确认监控窗口中的限位(Over-Travel)项目是否变为白色。

请按照以下顺序进行操作。

### [在系统板连接器(CNLS)上检查的方法]

{% hint style="warning" %}

警告(Warning)
连接和拔出电缆时，务必在控制器电源关闭的状态下执行。电气风险可能导致人身事故和财产损失。

{% endhint %}

通过系统板的 CNLS 连接器判断板的故障。请按照下图，在 CNLS 连接器处跳接与限位SW输入相关的引脚。在此状态下，通过专用输入信号监控窗口确认限位(Over-Travel)项目。

① 如果变为白色，则系统板故障。请更换该板。<br>
② 如果仍然是黄色错误状态，则请检查从系统板到本体限位开关之间的区域是否发生故障。<br>

### [在线束(C(M)ER1或C(M)EC1)上检查的方法]

{% hint style="warning" %}

警告(Warning)
连接和拔出电缆时，务必在控制器电源关闭的状态下执行。电气风险可能导致人身事故和财产损失。

{% endhint %}

通过线束连接器 C(M)ER1 或 C(M)EC1 判断电缆故障。首先从控制器拆下 C(M)EC1 线束，然后在附着于控制器的 C(M)EC1 连接器处跳接与限位SW相关的引脚。在此状态下，通过专用输入信号监控窗口确认限位(Over-Travel)项目。

① 如果变为白色，<br>
则为控制器内部的 C(M)EC1 连接器与系统板之间的电缆或连接器故障。请检查或更换它。

② 如果仍然是黄色错误状态，<br>
请检查从 C(M)EC1 连接器到本体限位开关之间的区域是否发生故障。

将 C(M)EC1 线束重新连接，拆下本体的 C(M)ER1 线束，然后在线束的 C(M)ER1 连接器处跳接与限位SW相关的引脚。在此状态下，通过专用输入信号监控窗口确认限位(Over-Travel)项目的状态。

① 如果变为白色，<br>
则为 C(M)ER1 连接器与 C(M)EC1 连接器之间的线束电缆或连接器故障。请检查或更换它。

② 如果仍然是黄色错误状态，<br>
请检查本体侧 C(M)ER1 连接器之后到限位SW之间的区域是否发生故障。

### [检查限位SW及本体内部布线的方法]

{% hint style="warning" %}

警告(Warning)
连接和拔出电缆时，务必在控制器电源关闭的状态下执行。电气风险可能导致人身事故和财产损失。

{% endhint %}

拆下本体的 CER1 线束后，使用万用表在本体的 CER1 连接器处检查与限位SW相关的线路是否存在异常。

① 如果测得电阻为开路状态，<br>
则为限位SW或限位SW – CER1 之间的连接器或连接器故障。请检查或更换它。

② 如果测得电阻为短路状态，<br>
则需检查其他部分是否发生故障。请联系我方。

### [检查安全板(BD632)的方法]

![](../_assets/3-Safety-io/E00002/그림9.png)<br>
图 9 安全板(BD632)

1) 检查 IO 电源状态的方法<br>
A. 确认上图中的两个 LED 是否为绿色点亮<br>
B. 如果 IO 电源 LED 为红色或熄灭，则检查所示的保险丝是否正常。<br>
C. 如果保险丝断开，请更换保险丝。<br>

2) 检查电机启动时 IO 电源是否不稳定的状态<br>
A. 启动电机时确认 IO 电源 LED 是否为绿色点亮。 <br>
B. 如果启动电机时瞬间变为红色或熄灭，则表示启动电机时 IO 电源不稳定。<br>

3) 如果 IO 电源状态不稳定<br>
A. 检查 IO 电源连接器的连接状态<br>
B. 检查 IO 电源电缆<br>
C. 检查安全板(BD632)的接地状态（接地电缆、接地端子连接状态）<br>
