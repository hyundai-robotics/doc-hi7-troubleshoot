# E00002. 硬件限位开关正在工作

## 1. 概述

机器人各轴的工作区域末端安装的限位开关已被触发。为了安全，机器人立即停止，无法进行正常操作，直到以适当的方法移动到安全工作区域。

## 2. 原因及检查

* 检查线束(C(M)ER1或C(M)EC1)的方法

### [工作区域脱离时的恢复方法]

在硬件限位开关被触发的状态下移动机器人，需要按照以下条件和顺序进行操作。

A) 进入手动模式，然后进入系统模式。 <br>
B) 在教导面板上按住启用开关。<br>

『手动模式』+ 『系统』+ 『TP的启用开关 ON』

C) 在此状态下打开电机。<br>
D) 使用微调键将机器人移回工作区域。<br>

(2) 尽管未脱离工作区域，但仍然发生错误的情况

首先，请在教导面板的专用输入信号窗口中检查限位（超行程）项目是否持续输入。您可以选择“『窗口调整』→『选择』→『系统输入』”来查看此窗口。限位（超行程）项目如果显示为黄色，则表示发生错误。

### [注意]
在手动模式下，必须打开教导面板的启用开关才能进行监控。在自动模式下，无论启用开关状态如何，均会进行监控。

主要检查要点和顺序为

A) 系统板<br>
B) 控制器内部的接线和连接器<br>
C) 线束及连接器<br>
D) 限位开关及本体接线<br>

需要在合适的位置跳线限位开关的输入线，以确认监控窗口中限位（超行程）项目是否变为白色。

### [在系统板连接器(CNLS)上检查的方法]

{% hint style="warning" %}

警告(Warning)
在连接和拆卸电缆时，必须确保控制器的电源处于关闭状态。电气风险可能导致人身事故和财产损失。

{% endhint %}

通过系统板的 CNLS 连接器判断板子是否故障。请如图所示在 CNLS 连接器的限位SW输入相关引脚上跳线短接。在此状态下，通过专用输入信号监控窗口检查限位（超行程）项目。

① 如果变为白色，则表示系统板故障。请更换电路板。<br>
② 如果仍然为黄色错误状态，则请检查系统板后到本体限位开关之间的区域故障。<br>

### [在线束(C(M)ER1或C(M)EC1)上检查的方法]

{% hint style="warning" %}

警告(Warning)
在连接和拆卸电缆时，必须确保控制器的电源处于关闭状态。电气风险可能导致人身事故和财产损失。

{% endhint %}

通过线束连接器 C(M)ER1 或 C(M)EC1 判断电缆故障。在此之前，请将 C(M)EC1 线束从控制器上拆卸，然后在控制器上附着的 C(M)EC1 连接器上跳线短接限位SW相关引脚。在此状态下，通过专用输入信号监控窗口检查限位（超行程）项目。

① 如果变为白色，<br>
则表示控制器内部的 C(M)EC1 连接器 – 系统板之间的电缆或连接器故障。请检查或更换。

② 如果仍然为黄色错误状态，<br>
则检查 C(M)EC1 连接器后到本体限位开关之间的区域故障。

重新连接 C(M)EC1 线束，在本体上拆卸 C(M)ER1 线束后，在线束的 C(M)ER1 连接器上跳线短接限位SW相关引脚。在此状态下，通过专用输入信号监控窗口检查限位（超行程）项目的状态。

① 如果变为白色，<br>
则表示 C(M)ER1 连接器 – C(M)EC1 连接器之间的线束电缆或连接器故障。请检查或更换。

② 如果仍然为黄色错误状态，<br>
则检查本体侧 C(M)ER1 连接器后到限位SW之间的区域故障。

### [检查限位SW及本体内部接线的方法]

{% hint style="warning" %}

警告(Warning)
在连接和拆卸电缆时，必须确保控制器的电源处于关闭状态。电气风险可能导致人身事故和财产损失。

{% endhint %}

拆卸本体上的 CER1 线束后，使用万用表在本体的 CER1 连接器上检查限位SW相关线路是否有异常。

① 如果测量阻抗为开路状态，<br>
则表示限位SW 或限位SW – CER1 间的连接器或连接器故障。请检查或更换。

② 如果测量阻抗为短路状态，<br>
则需要检查其他部分的故障。请联系我方。

### [检查安全板(BD632)的方法]

![](../_assets/3-Safety-io/E00002/그림9.png)<br>
图 9 安全板(BD632)

1) 检查 IO 电源状态的方法<br>
A. 确认上图中的两个 LED 是否呈绿色点亮状态<br>
B. 如果 IO 电源 LED 为红色或熄灭，请检查显示的保险丝是否正常状态。<br>
C. 如果保险丝断开，请更换保险丝。<br>

2) 确认电机开启时 IO 电源是否不稳定<br>
A. 检查电机开启时 IO 电源 LED 是否呈绿色点亮状态。<br>
B. 如果电机开启瞬间变为红色或熄灭，则表示电机开启时 IO 电源不稳定。<br>

3) 如果 IO 电源状态不稳定<br>
A. 确认 IO 电源连接器的连接状态<br>
B. 检查 IO 电源电缆<br>
C. 检查安全板(BD632)接地状态（接地电缆、接地端子连接状态）<br>
