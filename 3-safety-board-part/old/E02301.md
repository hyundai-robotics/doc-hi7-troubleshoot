# E2301. CPUERR 信号不匹配 (H6COM 任务错误)

## 1. 概述

发生了 CPUERR 信号不匹配 (H6COM 任务错误) 异常。当 H6COM-T 的某些任务的执行时间或执行周期超过正常范围时，可能会触发该警报。在这种情况下，系统将无法使电机开启。

## 2. 原因及检查

{% hint style="info" %}

(1) 主控任务周期不在正常范围内的情况
* 未安装最新版本的软件
* 外部设备的通信异常对系统造成影响

(2) 安全板 (BD632) 存在异常的情况
* 检查安全板 (BD632) 的方法

{% endhint %}


### (1) 主控任务周期不在正常范围内的情况

#### [未安装最新版本的软件]

通过 TP 屏幕移至服务 -> 系统诊断 -> 系统版本，确认当前安装的版本是否为最新版本的软件。

#### [外部设备的通信异常对系统造成影响的情况]

根据外部设备的通信是否激活，可能会对系统造成影响。在这种情况下，请根据 /tIOMain0 的任务执行时间进行比较。

如果最大执行时间超过 10000 usec，请与软件开发团队讨论使用条件。

#### [任务执行时间确认方法]
窗口设置 -> 分割 (上下) -> 点击下方窗口 -> 选择按钮 -> 选择任务监控

按下初始化按钮后，等待一定时间（约 10 分钟）确认最大执行时间
 

### (2) 安全板 (BD632) 存在异常的情况

#### [检查安全板 (BD632) 的方法]

 ![](../_assets/3-Safety-io/E02301/그림9.png)<br>

1) 确认 IO 电源状态的方法<br>
A. 确认上图中的两个 LED 是否为绿色点亮状态<br>
B. 若 IO 电源 LED 为红色或熄灭，请确认标示的保险丝是否正常状态。<br>
C. 若保险丝断开，请更换保险丝。<br>

2) 确认电机开启时 IO 电源是否处于不稳状态<br>
A. 确认电机开启时 IO 电源 LED 是否为绿色点亮状态。 <br>
B. 若电机开启瞬间变为红色或熄灭，则说明电机开启时 IO 电源处于不稳状态。<br>

3) 若 IO 电源状态不稳定<br>
A. 确认 IO 电源连接器的连接状态<br>
B. 检查 IO 电源电缆<br>
C. 检查安全板 (BD632) 接地状态 (接地电缆、接地端子连接状态)<br>
