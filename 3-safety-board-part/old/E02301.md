# E2301. CPUERR 信号不一致 (H6COM 任务错误)

## 1. 概述

发生了 CPUERR 信号不一致 (H6COM 任务错误) 异常。当 H6COM-T 的某些任务的执行时间或执行周期超过正常范围时，可能会发生该警报。在这种情况下，系统无法启动电机。

## 2. 原因及检查


{% hint style="info" %}

(1) 主控制器的任务周期不在正常范围内时
* 未安装最新版本的软件
* 外部设备的通信异常影响系统时

(2) 安全板 (BD632) 存在异常
* 检查安全板 (BD632) 的方法

{% endhint %}


### (1) 主控制器的任务周期不在正常范围内时

#### [未安装最新版本的软件]

在 TP 屏幕上，依次选择服务 -> 系统诊断 -> 系统版本，确认当前安装的版本是否为最新版本的软件。

#### [外部设备的通信异常影响系统时]

根据外部设备的通信激活与否，可能会影响系统。在这种情况下，请根据 /tIOMain0 的任务执行时间进行比较。

如果最大执行时间超过 10000 usec，请与软件开发团队讨论使用条件。

#### [检查任务执行时间的方法]
窗口设置 -> 分割(上下) -> 按下下方窗口 -> 选择按钮 -> 选择任务监控

### (2) 安全板 (BD632) 存在异常

#### [检查安全板 (BD632) 的方法]

 ![](../_assets/3-Safety-io/E02301/그림9.png)<br>

1) 检查 IO 电源状态的方法<br>
A. 确认上图中的两个 LED 是否呈绿色点亮状态<br>
B. 如果 IO 电源 LED 为红色或熄灭，检查所示的保险丝是否处于正常状态。<br>
C. 如果保险丝断了，请更换保险丝。<br>

2) 检查电机开启时 IO 电源是否不稳定<br>
A. 确认电机开启时 IO 电源 LED 是否为绿色点亮状态。<br>
B. 如果在电机启动瞬间变为红色或熄灭，则电机开启时 IO 电源处于不稳定状态。<br>

3) 当 IO 电源状态不稳定时<br>
A. 检查 IO 电源连接器的连接状态<br>
B. 检查 IO 电源电缆<br>
C. 检查安全板 (BD632) 接地状态 (接地电缆、接地端子连接状态)<br>
