# E02200. 本体限制SW运行中

## 1. 概述

机器人各轴的运动区域尽头安装的限制开关已动作。为安全起见，机器人会立即停止并在移动到安全运动区域之前无法正常运转。

## 2. 原因及检查方法

{% hint style="info" %}

(1) 机器人已超出硬件运动区域。

(2) 请将机器人移动到运动区域内。
* 超出运动区域时的恢复方法

{% endhint %}

(1) 机器人已超出硬件运动区域。

请再次确认机器人是否真的超出运动区域。同时可能会发生软件限制错误，机器人已经超出最大运动区域。请通过适当的操作将机器人移回运动区域内。

运动区域因机器人型号而异。因此，限制开关的安装位置可能不同，请参考相关机构维护说明书中记载的“运动范围限制”部分。

(2) 请将机器人移动到运动区域内。

请参考以下超出运动区域时的恢复方法，将机器人移回运动区域内。

* 超出运动区域时的恢复方法

在硬件限制开关闭合的状态下，要移动机器人，需要按以下条件和顺序执行。

A) 进入手动模式后切换到系统模式。<br>
B) 在示教挂件上按住使能开关。<br>

『手动模式』+ 『系统』+ 『TP的使能开关 ON』

C) 在此状态下打开电机。<br>
D) 使用 Jog 按钮将机器人移动到运动区域内。<br>
