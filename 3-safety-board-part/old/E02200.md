# E02200. 本体限制SW动作中

## 1. 概述

机器人的每个轴端安装的限制开关已操作。为了安全，机器人会立即停止，直到安全移动到正常的操作区域为止，无法进行正常操作。

## 2. 原因及检查方法

{% hint style="info" %}

(1) 机器人已脱离硬件操作区域。

(2) 请将机器人移动到操作区域内。
* 脱离操作区域时的恢复方法

{% endhint %}

(1) 机器人已脱离硬件操作区域。

请再次确认机器人是否确实脱离了操作区域。软限制错误也可能同时发生，机器人已经脱离了最大操作区域。请通过适当的操作将机器人移回操作区域内。

![](../_assets/3-Safety-io/E02200/그림1.png)<br>
图 1 E02200 本体限制SW动作中发生

操作区域因机器人模型而异。因此，限制开关的安装位置也可能不同，请参阅该设备的维修说明书中关于“操作范围限制”的部分。

![](../_assets/3-Safety-io/E02200/그림2.png)<br>
图 2 硬件限制SW安装位置的示例（HS165/HS200）

![](../_assets/3-Safety-io/E02200/그림3.png)<br>

(2) 请将机器人移动到操作区域内。

请参阅以下脱离操作区域时的恢复方法，将机器人移回操作区域内。

* 脱离操作区域时的恢复方法

在硬件限制开关被锁定的状态下，机器人运动需要按照以下条件和顺序进行操作。

A) 进入手动模式，然后切换到系统模式。<br>
B) 在教学挂件上按住使能开关。<br>

『手动模式』+ 『系统』+ 『TP的使能开关ON』

C) 在此状态下启动电机。<br>
D) 使用操作键将机器人移入操作区域内。<br>
