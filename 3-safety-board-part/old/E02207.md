# E02207. 本体限位SW输入不一致（安全链1 OFF）

## 1. 概述

尽管机器人没有超过软限位区域，但安装在机器人各轴运动区域尽头的限位SW被记录为已动作。由于安全链1的输入和安全链2的输入状态不同，因此需要检查。

## 2. 原因及检查方法

{% hint style="info" %}

在没有超过软限位的情况下，检测到硬件限位SW动作的异常情况。

请检查开关或线路系统是否存在问题。

{% endhint %}

图1 E02207 本体限位SW输入不一致（安全链1 OFF）发生

在没有超过软限位的情况下，检测到硬件限位SW动作的异常情况。安全链1处于开放状态，因此发生了问题。请检查与此相关的开关或线路系统。

* 硬件限位开关故障：开关损坏或因任何原因处于开放状态。
* 线路：线路中断或损坏，导致接触不良。
* 连接器：连接器松脱或损坏，导致接触不良等断线问题。

详细的检查要点请参阅“硬件限位开关检查方法”项。
