# E0014. 安全开关（EM, OTR, TS 等）瞬时接触

## 1. 概述

由于某种原因，提供给放大器的电机电源被切断。主控制器会检查安全信号以确认电机电源被切断的原因，当在安全信号输入中没有发现异常时，就会显示此消息。

下图展示了可能切断电机电源的各种安全信号的构成。主控制器定期检查这些安全信号的 ON/OFF 状态。如果在该周期内发生小于该周期的瞬时接触故障，主控制器将无法检测到并显示此消息。

图 1 电机电源开关的安全电路概念图

## 2. 原因及检查

{% hint style="info" %}

(1) 检查 DC 24V 电源及电缆状态。

(2) 检查安全开关及信号接线。

(3) 检查系统板、电气模块。

{% endhint %}

### (1) 检查 DC24V 电源及电缆状态。

确认系统板上 DC24V 控制电源是否正常供应。如果电源有异常，可能会影响系统板的安全序列，从而导致此错误发生。

对于 Hi6-N 控制器，电源通过电气模块的 CN24VB3、CN24VB4 连接器——系统板的 CNSMPS1、CNSMPS2 连接器供应。请检查电源是否波动或电缆是否有异常部分。

![](../_assets/3-Safety-io/E00014/그림2.png)<br>
图 2 Hi6-N 系统板（BD632）的 DC24V 电源连接及电压确认方法

对于 Hi6-T 控制器，电源通过 SMPS & BUFFER 连接器——背板 CN24VB1 连接器，以及背板与系统板之间的板到板连接供应。请检查电源是否波动或电缆是否有异常部分。

![](../_assets/3-Safety-io/E00014/그림3.png)<br>
图 3 Hi6-N 系统板（BD632）的 DC24V 电源连接及电压确认方法

### (2) 检查安全开关及信号接线。

安全开关输入可能出现瞬间 OFF 的现象，导致 MAIN 板无法识别。其原因可能为：

* 开关故障
* 接线故障：电缆磨损等损坏可能是原因。
* 接线的铺设问题：
动力线与消耗较大电力的电缆之间的距离应至少保持 10cm 以上。或者需使用金属材料的板等进行电磁屏蔽。

{% hint style="warning" %}

注意：这会忽视与安全相关的功能，仅供测试使用，请立即恢复原状。如果在忽视的状态下使用，可能会引发安全问题。

{% endhint %}

### (3) 检查系统板、电气模块。

* 电缆连接（电线、连接器等）故障

对于 Hi6-N 控制器，检查装有电子接触器的电气模块（PSM 或 PDM）与收集监控信号的系统板之间的电缆连接。电缆名称为 CNMC，通过系统板下方前面连接到电气模块。请检查此电缆的连接状态。

![](../_assets/3-Safety-io/E00014/그림14.png)<br>
图 4 Hi6-N 控制器 

对于 Hi6-T 控制器，电子接触器安装在 PCB 板上，并通过板到板的连接收集监控信号。请检查板到板的连接状态。

![](../_assets/3-Safety-io/E00014/그림15.png)<br>
图 5 电气模块与系统板之间的 CNMC 电缆

* 系统板故障

系统板内部输入信号处理部分的故障也可能导致错误的发生。请更换系统板以进行确认。

* 电气模块故障（仅 Hi6-N 控制器）

电气模块内部的故障可分为电气板（BD6C2）、电子接触器（MC1、MC2）及电气板与电子接触器之间的接线。然而，在机器人已安装的现场检查电气模块内部是困难的，请更换整个电气模块。
