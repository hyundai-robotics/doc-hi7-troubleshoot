# E0014. 安全开关(EM, OTR, TS等) 瞬时接触

## 1. 概述

由于某种原因，供给放大器的电机电源被切断。主控系统通过检查安全信号来确定电机电源被切断的原因，当未发现安全信号输入异常时，会显示此消息。

下图显示了可以切断电机电源的各种安全信号的构成。主控系统定期检查这些安全信号的 ON/OFF 状态。如果在这个周期内发生小于周期的瞬时时间接触不良，主控系统将无法感知并显示此消息。

## 2. 原因及检查

{% hint style="info" %}

(1)	请检查 DC 24V 电源及电缆状态。

(2)	请检查安全开关及信号配线。

(3)	请检查系统板和电气模块。

{% endhint %}

### (1)	请检查 DC24V 电源及电缆状态。

请确认系统板上 DC24V 控制电源是否正常供给。如果电源出现异常，将会影响系统板的安全序列，从而导致此错误。

对于 Hi6-N 控制器，电源通过电气模块的 CN24VB3、CN24VB4 连接器 - 系统板 CNSMPS1、CNSMPS2 连接器供电。请确认电源是否波动或电缆是否存在异常部分。

![](../_assets/3-Safety-io/E00014/그림2.png)<br>
图 2 Hi6-N 系统板(BD632)的 DC24V 电源连接及电压确认方法

对于 Hi6-T 控制器，电源通过 SMPS & BUFFER 连接器 – Back Plane 板 CN24VB1 连接器以及 Back Plane 板和系统板之间的板间连接供电。请确认电源是否波动或电缆是否存在异常部分。

![](../_assets/3-Safety-io/E00014/그림3.png)<br>
图 3 Hi6-N 系统板(BD632)的 DC24V 电源连接及电压确认方法

### (2)	请检查安全开关及信号配线。

安全开关输入可能出现瞬间 OFF 的现象，以至于 MAIN 板无法识别。可能的原因有：

* 开关故障
* 配线故障：电缆磨损等损毁可能是原因。
* 配线敷设问题：
动力线和大电流消耗电缆的间距必须在 10cm 以上。或者使用金属材料的板等进行电子屏蔽。

{% endhint %}

### (3)	请检查系统板和电气模块。

* 电缆连接（电线、连接器等）故障

对于 Hi6-N 控制器，需检查电子接触器安装于电气模块(PSM 或 PDM)与收集监控信号的系统板之间的电缆连接。电缆名称为 CNMC，通过系统板底部前面进入电气模块。请检查该电缆的连接状态。

![](../_assets/3-Safety-io/E00014/그림14.png)<br>
图 4 Hi6-N 控制器

对于 Hi6-T 控制器，电子接触器安装在 PCB 板上，并通过板间连接收集监控信号。请检查板间连接状态。

![](../_assets/3-Safety-io/E00014/그림15.png)<br>
图 5 电气模块与系统板之间的 CNMC 电缆

* 系统板故障

系统板内部输入信号处理部分的故障也可能导致错误发生。请更换系统板以进行确认。

* 电气模块故障（仅 Hi6-N 控制器）

电气模块内部的故障可分为电气板(BD6C2)、电子接触器(MC1, MC2)和电气板与电子接触器之间的连线。然而在机器人已经安装的现场，检查电气模块内部是困难的，因此请更换整个电气模块。
