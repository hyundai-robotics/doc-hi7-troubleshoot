# E02280. 尝试启动伺服时电子接触器(MC1)故障/检测异常

## 1. 概述

在尝试启动伺服时，磁区（电子接触器，magnetic contactor）MC1未能正常工作。

## 2. 原因及检查方法

{% hint style="info" %}

(1)	检查监控系统。<br>
(2)	检查磁区MC1。<br>
(3)	检查电气板。<br>
(4)	检查伺服安全板。<br>

{% endhint %}

(1)	检查监控系统。

检查安装了电子接触器的电气模块（PSM或PDM）与收集监控信号的伺服安全板之间的电缆。电缆名称为CNMC，通过伺服安全板底部前方进入电气模块。检查此电缆的连接状态。

![](../_assets/3-Safety-io/E02280/그림1.png)<br>
图 1 Hi6-N 控制器

(2)	检查磁区MC1。

检查电气模块内部的磁区MC1是否正常工作。

![](../_assets/3-Safety-io/E02280/그림3.png)<br>
图 3 Hi6-N 控制器（安装在电气模块内部的磁区MC2）

(3)	检查电气板。<br>
可能存在伺服安全板与磁区之间的电气板、电缆布线问题，请进行检查或更换。

![](../_assets/3-Safety-io/E02280/그림5.png)<br>
图 5 Hi6-N 控制器（安装在电气模块内部的电气板）

(4)	检查系统板。<br>
如果监控系统、磁区、电气板没有问题，请更换伺服安全板。
