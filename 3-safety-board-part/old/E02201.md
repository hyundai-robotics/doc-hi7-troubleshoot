# E02201. 主体限位SW输入不一致（安全链1 OFF）

## 1. 概述

机器人超出了软限位区域。然而，安装在每个轴的工作区域末端的限位开关输入并不正常。由于安全链1的输入和安全链2的输入不同，因此需要检查。

## 2. 原因及检查方法

{% hint style="info" %}

(1) 如果没有超出硬件工作区域
* 安全链1存在问题，请检查限位SW接线。

(2) 如果超出了硬件工作区域
* 安全链2存在问题，请检查限位SW接线。

{% endhint %}

(1) 如果没有超出硬件工作区域

图1 E02201主体限位SW输入不一致（安全链1 OFF） – 硬件工作区域内部

安全链1存在问题，请检查限位SW接线。

尽管在安装有硬件限位SW的区域内，但安全链1被监测为OFF。这可能由以下原因引起。

* 硬件限位SW故障：开关损坏或因某种原因处于打开状态。
* 接线：接线断开或受损导致接触不良。
* 连接器：连接器松脱或损坏导致接触不良等断线问题。

详细检查重点请参阅“硬件限位开关检查方法”一节。

(2) 如果超出了硬件工作区域

图2 E02201主体限位SW输入不一致（安全链1 OFF） – 硬件工作区域外部

安全链2存在问题，请检查限位SW接线。

尽管机器人已超出了安装有硬件限位SW的区域，但安全链2未能检测到异常。换句话说，安全链2始终保持闭合状态。这可能由以下原因引起。

* 硬件限位SW故障：开关损坏或因某种原因短路。
* 接线：一对接线的两条线路短路。
* 连接器：连接器受损导致针脚间短路问题。

详细检查重点请参阅“硬件限位开关检查方法”一节。
