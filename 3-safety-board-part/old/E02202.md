# E02202. 本体限制SW输入不一致 (安全链2 OFF)

## 1. 概述

机器人已超出软限制区域。然而，安装在机器人各轴运动区域末端的限制开关输入不正常。安全链1的输入与安全链2的输入不同，因此需要检查。

## 2. 原因及检查方法

{% hint style="info" %}

(1)	如果未超出硬件运动区域
* 安全链2存在问题，请检查限制SW接线。

(2)	如果超出硬件运动区域
* 安全链1存在问题，请检查限制SW接线。

{% endhint %}

(1)	如果未超出硬件运动区域

图1 E02202 本体限制SW输入不一致 (安全链2 OFF) – 硬件运动区域内部

安全链2存在问题，请检查限制SW接线。

尽管在硬件限制SW安装的区域内，但安全链2被监测为OFF。这可能由以下原因引起：

* 硬件限制SW故障：开关损坏或因某种原因处于打开状态。
* 接线：接线断裂或损坏导致接触不良。
* 连接器：连接器脱落或损坏，使接触不良等断线问题发生。

详细检查要点请参见“硬件限制开关检查方法”项。

(2)	如果超出硬件运动区域

图2 E02202 本体限制SW输入不一致 (安全链2 OFF) – 硬件运动区域外部

安全链1存在问题，请检查限制SW接线。

尽管机器人已超出硬件限制SW安装的区域，但安全链1未能检测到异常。即安全链1持续处于闭合状态。可能由以下原因引起：

* 硬件限制SW故障：开关损坏或因某种原因处于短路状态。
* 接线：一对接线中的两条线短路。
* 连接器：连接器损坏导致针脚间短路问题发生。

详细检查要点请参见“硬件限制开关检查方法”项。
