# E02202. 本体限位SW输入不一致（安全链2 OFF）

## 1. 概述

机器人已超出软限位区域。然而，安装在各轴动作区域末端的限位开关输入不正常。由于安全链1的输入和安全链2的输入不同，因此需要进行检查。

## 2. 原因与检查方法

{% hint style="info" %}

(1)	如果没有超出硬件动作区域
* 由于安全链2存在问题，请检查限位SW接线。

(2)	如果超出硬件动作区域
* 由于安全链1存在问题，请检查限位SW接线。

{% endhint %}

(1)	如果没有超出硬件动作区域

图1 E02202本体限位SW输入不一致（安全链2 OFF） – 硬件动作区域内部

由于安全链2存在问题，请检查限位SW接线。

尽管处于硬件限位SW安装区域内，但安全链2被监测为OFF。这可能是以下原因造成的：

* 硬件限位SW故障：开关损坏或由于其他原因而打开（Open）。
* 接线：接线断裂或损坏导致接触不良发生。
* 连接器：连接器脱落或损坏导致接触不良等短路问题发生。

详细检查要点请参考“硬件限位开关检查方法”章节。

(2)	如果超出硬件动作区域

图2 E02202本体限位SW输入不一致（安全链2 OFF） – 硬件动作区域外部

由于安全链1存在问题，请检查限位SW接线。

尽管机器人已超出硬件限位SW安装区域，但安全链1未能检测到异常。即安全链1始终处于闭合状态。这可能是以下原因造成的：

* 硬件限位SW故障：开关损坏或由于其他原因而短路（Short）。
* 接线：一对接线的两条线路短路。
* 连接器：连接器损坏导致针间短路问题发生。

详细检查要点请参考“硬件限位开关检查方法”章节。
