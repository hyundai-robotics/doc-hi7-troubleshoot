# 安全注意事项

为了确保产品的正确使用和用户的安全，并防止财产损失，请务必在使用产品之前详细了解以下安全注意事项。

### 危险

{% hint style="danger" %}
\[危险\] 紧急危险：未遵守时，操作员可能会死亡或重伤。
{% endhint %}

* 熟悉说明书中的产品安装内容，并遵循指示将机器人产品和其他设备进行安装。
* 如果软件发生严重错误，请立即停止使用并联系客户支持团队。
* 如果产品发生故障或损坏等问题，请立即停止使用并联系客户支持团队。

### 警告

{% hint style="warning" %}
\[警告\] 潜在危险：未遵守时，操作员可能会受伤或产品严重损坏，导致财产损失。
{% endhint %}

* 使用的安全设备必须通过安全接点端子或设置为Safety I/O的可配置数字I/O以双重信号连接。连接到常规接点端子或单一信号连接时，将无法满足规定的安全水平。
* 请勿将手指等身体部位伸入控制器的内部支架后面。存在触电或受伤的风险。
* 机器人应用系统制造商或机器人用户须熟悉说明书内容并完成产品操作培训。
* 为了工人的安全，在安装产品之前，请务必设置安全围栏等适当的安全设施。
* 检查规格信息，使用合适的固定螺钉，并按照指定的扭矩拧紧。如果螺钉松动，机器人可能会从安装地点脱落或损坏。
* 注意确保产品的连接部（电源和电缆）不进入液体、灰尘、金属粉尘等导电异物。此外，请勿用尖锐物体刺入连接处或在连接电缆时施加过大的力量。连接端子的腐蚀或暂时短路可能导致产品爆炸或起火。
* 检查接线信息并使用适当的端子连接设备。特别是安全设备，如果连接到常规端子，将无法保证安全功能，因此必须连接到安全设备用端子上。
* 请勿使用损坏的电缆，且在使用产品时请勿断开电源。这可能导致触电、火灾、故障和受伤。
* 长时间使用产品会产生热量，存在烧伤等受伤的风险。如果需要触摸产品，请先关闭电源，并放置超过1小时以充分冷却。
* 使用示教 pendant 时请注意机器人的运动。
* 如果示教 pendant 上警告致命错误，请即刻按下紧急停止开关停止机器人，找出原因并解决错误。如果无法解决错误，请联系客户支持团队。
* 请勿擅自安装、改装、拆解或修理产品。这可能导致故障和事故。同时，对于由此导致的产品损坏和破坏，我们不承担责任。

### 注意

{% hint style="warning" %}
\[注意\] 低风险因素：未遵守时，操作员可能会受到轻微伤害或产品损坏，导致财产损失。
{% endhint %}

* 请勿随意安装或改装、拆解、修理产品。此外，禁止除我们公司的专业人员外的任何人随意改装产品或附加部件。如因此导致产品故障，将无法获得免费的服务和质量保证服务。
* 合格的安装专业人员必须遵循该国家和地区的相关规定和法律来安装产品。安装和修理产品时，请联系客户支持团队并委托给专业人员。
* 请勿在多尘或肮脏的地方安装和使用产品。灰尘或异物可能导致产品故障或性能异常。
* 请勿在具有磁性或受磁性影响的地方或存在电磁干扰的地方安装和使用产品。因磁性可能导致产品损坏或性能异常。
* 操作产品时，请勿穿着宽松的衣物或饰品，长发者应扎起，以免夹在机器人的关节等处。
* 产品运行时，请勿进入工作范围或触碰机器人。存在受伤的风险。
* 产品请在包装状态下运输，以避免破损，并存放在湿度低的干燥地点。包装材料内部的湿气可能会损坏或导致产品故障。
* 产品应避免存放在温度和湿度易变化的地方，并存放在干净、凉爽和干燥的地方。
* 产品运输时请保持正确姿势，并两人以上一起工作。可能会导致腰部、手臂或腿部等身体部位受伤。
* 使用提升设备搬运产品时，请遵循该国家和地区的安全法规和设备使用指南。
* 请熟悉说明书中的运输内容，并遵循指示运输产品。对于因客户运输产品而导致的损坏和破坏，我们不承担责任。
