# 关于本说明书

本说明书介绍了HD现代机器人Hi7控制器的基本事项和结构，以及工业机器人的常见操作。每一章不仅介绍了基本操作方法，还说明了多种应用功能的使用方法。

本说明书不详细讨论使用协作机器人进行直接教导和安全功能设置方法、点焊功能、弧焊功能、定位器同步功能、传感器同步功能等应用功能。有关详细信息，请参考协作机器人维护说明书和按功能分类的说明书。

在使用产品之前，请务必充分了解说明书的内容。此外，请将说明书存放在易于查看的地方，以便随时查阅。
