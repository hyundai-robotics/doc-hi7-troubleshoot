## 2.11. E02541 驱动单元控制电压低

### 1. 概述

供应给伺服驱动单元的 +15V 控制电源已降至阈值以下。此错误通过根据控制器型号的不同路径检测，然后传输到伺服板。

*   Hi7-N：由伺服驱动单元直接检测。

### 2. 原因和检查方法

{% hint style="info" %}

*   < 检查电源 LED 指示灯 >

    (1)	请检查电源状态 LED。

    ->  Hi7-N：检查伺服驱动单元上的“POW” LED。

    ->  Hi7-T：将来会包含（待定）
    
    ->  Hi7-NX：将来会包含（待定）

    ->  检查 PSM（电源模块）上的 24V 控制电源电压。


*   < 如果板 LED 和 PSM LED 都是关闭状态 >

    (2)	请检查控制电源（PSM）的输出。

    -> Hi7-N 控制器

    *  断开连接到控制模块 BD604 的 CN24VB1 连接器，然后检查 PSM 上的 24V 输出状态 LED。

    *   拆下 BD642 板，然后检查伺服驱动单元上的“POW” LED 是否亮起。

    ->  Hi7-T 控制器：将来会包含（待定）

    -> Hi7-NX 控制器：将来会包含（待定）


    (3)	请检查控制电源单元（CMSMPS）。

    ->  检查供给 CMSMPS 的输入电压。

    ->  更换 CMSMPS 并检查状态 LED。

    * < 如果只有板 LED 是关闭状态 >

    (4)	更换相关组件并检查电源状态 LED。

    -> Hi7-N 控制器

    * 更换连接 PSM 和控制模块的 CN24VB1 电缆，然后检查 LED。

    * 更换伺服板 (BD642) 并检查 LED。

    * 更换伺服驱动单元并检查 LED。

    ->  Hi7-T : 将来会包含（待定）

    ->  Hi7-NX : 将来会包含（待定）
