## 2.9. E02508 AMP PN 欠压检测路径错误或放电错误

Former Error Code: E0033 AMP PN 欠压生成

### 1. 概述

为电动机供电的伺服驱动单元的直流链路电压 (P-N) 已测量低于预设的欠压阈值。

### 2. 原因和检查方法

{% hint style="info" %}

在用于检测从二极管模块开始的PN电压下降的路径中发生了问题。或者，在PN放电电路中发生了异常。

* < 如果在电机关闭时仍然发生错误 >

  * Hi7-N 控制器

     (1) 检查与欠压错误检测相关的组件。
     
     -> 更换BD642电路板并验证错误是否仍然存在。

     -> 更换伺服驱动单元并验证错误是否仍然存在。

    
  * Hi7-T 控制器（未来将包含）

     (2) 检查与欠压错误检测相关的组件。
     
     -> 未来将包含（待定）

{% endhint %}

(1) 请检查与欠压错误检测相关的组件。

* BD642电路板的更换检查

   使用已知功能正常的单元更换BD642电路板。如果错误不再出现，原电路板有缺陷，应更换。

* 伺服驱动单元的更换检查

   负责检测AMP欠压错误的模块如下：

  -> Hi7-N 控制器：H7D6X（用于中型机器人）或H7D6A（用于小型机器人），不包括伺服板。

  请在进行检查之前验证您当前控制器中安装的特定组件。用已知功能正常的部件更换该单元，并验证错误是否重复出现。
