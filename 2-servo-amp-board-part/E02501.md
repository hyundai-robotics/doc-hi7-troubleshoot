## 2.2. E02501 AMP 再生放电电阻开路、电阻或电路错误

### 1. 概述

此错误发生在机器人减速或沿重力方向向下移动时产生的再生功率的消散过程中。它可能是由于过热检测传感器电路故障、电阻开路或三相电源过电压引起的。

### 2. 原因和检查方法

{% hint style="info" %}
过热错误也可能由于电阻开路或放电控制系统异常而发生。此外，再生电阻值的增加或三相电源电压的浪涌也可能触发此错误。

* < 如果错误在电机开启的瞬间始终发生 >

(1)	检查再生放电电阻的电阻值。

-> 检查 CNDR 电缆的电阻值。

(2)	检查伺服驱动单元。

-> 更换伺服驱动单元并验证错误是否仍然存在。

(3)	检查电源相关组件。

-> 检查控制器内部的三相电压。

-> 检查供给控制器的输入三相电压。

{% endhint %}

过热错误也可能由于电阻开路或再生电阻值增加而发生。
 
* 再生电阻开路检查

如果在 CNDR 电缆末端测得的电阻在几兆欧姆范围内，这表明电阻开路或内部接线接触不良。请用已知正常的单元替换再生电阻或修理接线。

* 控制器内部三相电压检查

再生放电操作在大约 DC 375V 开始。如果向伺服驱动单元供给的电压达到 AC 242V 或更高，再生电阻过热错误可能在电机开启的瞬间触发。如果输入电压超过允许范围，请根据控制器输入电压和内部三相电压检查程序进行检查。

-> 伺服驱动单元输入电压规格：三相 AC 220V
-> 电机开启时的允许范围：198V ~ 242V
