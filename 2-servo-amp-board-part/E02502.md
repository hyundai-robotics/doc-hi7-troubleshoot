## 2.3. E02502 AMP再生放电电阻检测电路错误

### 1. 概述

此错误与用于散热的电阻过热有关，该电阻用于在机器人减速或沿重力方向下移动时散发再生能量。通常是由于过热检测传感器电路故障或电缆相关问题引起的。

### 2. 原因和检查方法

{% hint style="info" %}

在用于检测过热错误的路径中发生了异常，或者电阻值发生了变化。

* < 如果在电机关闭时错误仍然持续发生 >

(1) 检查与过热错误检测相关的电缆。

-> 检查CNTR电缆的电阻。

(2) 检查与过热错误检测相关的组件。

-> Hi7-N 控制器：更换控制模块（包括BD642板）并验证错误是否仍然存在。

-> Hi7-T 控制器：（待日后补充）

-> 伺服驱动单元：更换伺服驱动单元并验证错误是否仍然存在。

{% endhint %}

(1) 请检查过热错误检测电缆。

再生电阻过热错误由伺服驱动单元通过监测附在电阻上过热传感器的ON/OFF状态来检测。 在Hi7-N控制器中，检测到的错误信号通过BD651/BD653板传输，经BD652/BD654处理后，最终由BD642板上的软件进行处理。

![](../_assets/2.서보AMP/E02502/E02502_1.png  )

图2.3.1. 再生电阻过热错误组件布局（Hi7-N控制器）

* CNTR电缆检查

检查连接到过热检测传感器的CNTR连接器处传感器是否有任何异常。在正常条件下，传感器电阻应小于0.1欧姆。

![](../_assets/2.서보AMP/E02502/E02502_2.png  )

图2.3.2. 在CNTR连接器处测量电阻（Hi7-N控制器）

(2) 请检查与过热错误检测相关的组件。

* 伺服控制板更换检查

用已知功能正常的单元更换伺服控制板。如果错误不再发生，则原始板有缺陷。请更换为正常部件以便继续使用。

-> Hi7-N 控制器：BD642

-> Hi7-T 控制器：待日后补充（TBD）

-> Hi7-NX 控制器：待日后补充（TBD）


* 伺服驱动单元更换检查

负责检测再生放电电阻过热错误的模块如下。

-> Hi7-N 控制器：中型机器人用H7D6X，小型机器人用H7D6A（不包括伺服板）。

-> Hi7-T 控制器：待日后补充（TBD）。

-> Hi7-NX 控制器：待日后补充（TBD）。

在进行检查之前，请确认您当前控制器中安装的具体组件。用已知功能正常的部件更换该单元，并验证错误是否再次发生。
