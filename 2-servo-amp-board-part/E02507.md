## 2.8. E02507 AMP二极管模块错误或AC输入电压不足

Former Error Code: E0033 AMP PN欠压产生

### 1. 概述

为电机供电的伺服驱动单元的直流联结电压（P-N）已测量低于预设的欠压阈值。

### 2. 原因和检查方法

{% hint style="info" %}

由于二极管模块的异常，PN电压未能充电。如果供电给伺服驱动单元的交流电压不足，则也可能发生此错误。

* < 如果错误发生在电机开启的瞬间 >

  * Hi7-N 控制器, NX 控制器

     (1) 检查电源相关组件。
     
     -> 更换伺服驱动单元并验证错误是否仍然存在。

     (2) 检查控制器的电源供电电压。

     -> 检查控制器内部的三相电压。
     
     -> 检查供电给控制器的输入三相电压。

  * Hi7-T 控制器

     (3) 检查电源相关组件。
     
     -> 更换BD667T板并验证错误是否仍然存在。

     (4) 检查控制器的电源供电电压。

     -> 检查控制器内部的单相电压。

     -> 检查供电给控制器的输入单相电压。

{% endhint %}

* Hi7-N 控制器

(1) 请检查电源相关组件。

当供电给伺服驱动单元的三相AC 220V输入超出允许范围时，会发生AMP欠压错误。如果再生放电控制电路中的异常在电机开启的瞬间触发放电操作，也可能发生此错误。

** 伺服驱动单元的更换检查

更换负责检测AMP欠压错误的模块，并验证错误是否重新出现。模块内的电路故障可能导致错误持续存在。

负责检测AMP欠压错误的模块如下：

-> 中型机器人：H7D6X

-> 小型机器人：H7D6A

(2) 请检查控制器的电源供电电压。

** 三相电压检查

AMP欠压错误在约DC 142V时触发。如果在供电给伺服驱动单元的电压低于AC 100V时开启电机，可能会发生欠压错误。如果输入电压超出允许范围，请按照控制器输入三相电压和内部三相电压检查程序进行检查。

-> 伺服驱动单元输入电压规格：三相AC 220V

-> 电机开启时的允许范围：AC 198V ~ 242V

* Hi7-T 控制器（将来包含）

(3) 请检查电源相关组件。

当供电给伺服驱动单元的单相AC 220V输入超出允许范围时，会发生AMP欠压错误。如果再生放电控制电路中的异常在电机开启的瞬间触发放电操作，也可能发生此错误。

** 伺服驱动单元的更换检查

更换负责检测AMP过压错误的模块，并验证错误是否重新出现。模块内的电路故障可能导致错误持续存在。

负责检测AMP欠压错误的模块如下：

-> 将来包含（待定）

(4) 请检查控制器的电源供电电压。

** 单相电压检查

AMP欠压错误在约DC 142V时触发。如果在供电给伺服驱动单元的电压低于AC 100V时开启电机，可能会发生欠压错误。如果输入电压超出允许范围，请按照控制器输入单相电压和内部单相电压检查程序进行检查。

-> 伺服驱动单元输入电压规格：单相AC 220V

-> 电机开启时的允许范围：AC 198V ~ 242V

* Hi7-NX 控制器（将来包含）
