## 2.6. E02505 AMP PN过电压检测路径错误或放电错误

Former Error Code: E0011 AMP P-N过电压产生

### 1. 概述

为电机供电的伺服驱动单元的直流链路电压（P-N）超过了预设阈值。

### 2. 原因和检查方法

{% hint style="info" %}

在用于从二极管模块检测PN电压下降的路径中发生了异常，或PN放电电路发生故障。

* < 如果错误在电机关闭时仍然持续发生 >

(1) Hi7-N 控制器

->  更换BD642板并验证错误是否仍然存在。

->  更换控制模块并验证错误是否仍然存在。

->  更换伺服驱动单元并验证错误是否仍然存在。

(2) Hi7-T 控制器

->  将在未来包含（待定）

(3) Hi7-NX 控制器

->  将在未来包含（待定）

{% endhint %}

(1) Hi7-N 控制器

在直流链路电源（P-N）供电超过预设水平时，Hi7-N 控制器 AMP 通过伺服驱动单元检测过电压错误。检测到的错误随后由BD642板通过AMP板（BD651、BD652、BD653或BD654）处理。

-> BD642板的更换检查

将BD642板替换为已知功能正常的单元。如果错误不再出现，则原始板存在缺陷。请用正常部件更换BD642，以便继续操作。

-> 伺服驱动单元的更换检查

负责检测AMP过电压错误的模块如下：

* Hi7-N 控制器：H7D6X（适用于中型机器人）或 H7D6A（适用于小型机器人），不包括伺服板。

在进行检查之前，请验证当前控制器中安装的特定组件。用已知功能正常的部件替换单元并验证错误是否复发。
