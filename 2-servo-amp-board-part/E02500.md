## 2.1. E02500 AMP Regenerative Discharge Resistor Overheat

### 1. Overview

此错误与用于消耗机器人减速或向重力方向下移动时产生的再生电能的电阻过热有关。它可能是由于冷却风扇性能下降、临时快速移动或由于连续机器人操作超过再生放电能力引起的。

### 2. Causes and Inspection Methods

{% hint style="info" %}

再生放电电阻的温度已超过参考值。这是由于机器人播放速度过快或冷却系统出现问题导致的。

* < 如果错误在特定步骤上发生，取决于机器人的播放速度 >

(1)	通过调整机器人的播放速度来验证错误。

(2)	检查再生放电电阻的电阻值。

* <如果错误在机器人运行5分钟或更长时间后发生>

(3)	检查控制器的冷却系统和再生电力的数量。

->	检查每个风扇的运行状态。

->	检查提供给风扇的电源电压。

(4)	检查机器人的再生电力负载。

->	通过降低机器人的播放速度来验证错误，以查看热负载是否减少。

{% endhint %}

(1)	通过调整机器人的播放速度来验证错误。

在机器人减速或向重力方向下移动时，伺服驱动单元的直流电压增加。为防止因电压突升而导致的部件损坏，电能通过再生放电电阻消耗。剧烈减速或朝重力方向的高速移动可能触发此错误。请验证错误是否根据机器人的播放速度发生。

* 改变机器人播放速度

如果机器人运动产生的再生电能超过控制器的设计规格，则可能会发生“再生电阻过热”错误。请在降低发生错误步骤的速度后操作机器人，并验证错误是否仍然存在。

(2)	检查再生放电电阻的电阻值。

* 再生放电电阻值的检查

如果在CNDR电缆末端测量的电阻值偏离手册中规定的值10%或更多，则电阻器有缺陷。请更换电阻器。有关详细测量程序，请参考前一页。

 (2)-1. Hi7-N Controller

-> 中型机器人的电阻值（H7D6X）：5 ohm（型号 N00-00, N00-70：两个2.5 ohm电阻串联连接）

-> 大型机器人的电阻值（H7D6X）：4 ohm（型号 N00-80）

-> 小型机器人的电阻值（H7D6A）：15 ohm（型号 N00-30）

(2)-2. Hi7-T Controller

-> 将在未来包含（待确定）

(2)-3. Hi7-NX Controller

-> 将在未来包含（待确定）

(3)	请检查控制器的冷却条件和再生电力的数量。

如果在机器人运行5分钟或更长时间后发生再生电阻过热错误，则表示控制器的冷却系统存在故障，或机器人的播放速度超过控制器的设计规格。风扇安装在控制器后方，以冷却伺服驱动单元的散热器和再生放电电阻。

* 风扇运行状态的检查

如果风扇不旋转或其速度异常低，请更换相应的风扇。冷却风扇的寿命因操作环境和总使用小时数而异。

* 风扇电源电压的检查

如果所有风扇都无法操作，请验证风扇输入电压。风扇输入电压设置为AC 220V，允许范围在额定电压的10%以内。如果电压低于额定值10%以上，由于风扇转速降低，冷却效率将降低。若电压偏低，请检查风扇电源连接器（CNFN2）及控制器的整体输入电压。

(4)	请检查机器人的再生电力负载。

* 根据机器人的播放速度验证错误。

如果在连续播放5分钟或更长时间内发生过热错误，可能是由于机器人的重复运动超过了控制器的冷却能力。请降低机器人的播放速度并验证错误是否仍然存在。如果通过降低速度解决了过热错误，但无法达到任务所需的周期时间，请联系技术支持部门。
