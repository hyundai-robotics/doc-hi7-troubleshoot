## 2.5. E02504 AMP二极管模块错误或交流输入电压超过阈值

### 1. 概述

为电机提供电源的伺服驱动单元的直流链接电压（P-N）已超过预设的直流395V阈值。

### 2. 原因和检查方法

{% hint style="info" %}

二极管模块中的异常导致PN电压超出允许范围。如果供应给伺服驱动单元（AMP）的三相交流电压异常高，也可能会发生此错误。

* < 如果错误在电机启动时持续发生 >

(1) 检查电源相关组件。

-> 更换伺服驱动单元并验证错误是否仍然存在。

(2) 检查电源电压。

-> 检查控制器的内部三相电压。

-> 检查供给控制器的输入三相电压。

{% endhint %}

(1) 请检查电源相关组件。

* 伺服驱动单元的替换检查

更换负责检测AMP过电压错误的模块，并验证错误是否重复出现。模块内的电路故障可能导致错误持续。

(1)-1. Hi7-N 控制器

-> 中型机器人的伺服驱动单元：H7D6X

-> 小型机器人的伺服驱动单元：H7D6A

(1)-2. Hi7-T 控制器

-> 电子行业机器人的伺服驱动单元：将来将包含（待定）

(1)-3. Hi7-NX 控制器

-> 大型机器人的伺服驱动单元：将来将包含（待定）

(2) 请检查电源电压。

* Hi7-N 和 NX 控制器：三相电压检查

如果有AC 242V或更高的电压供应给伺服驱动单元，在电机启动时可能会触发过电压错误。如果输入电压超过允许范围，请根据控制器输入电压和内部三相电压检查程序检查电压。

-> 伺服驱动单元输入电压规格：三相AC 220V

-> 电机启动时的允许范围：198V ~ 242V

* Hi7-T 控制器：单相电压检查（将来将包含）

如果有AC 242V或更高的电压供应给伺服驱动单元，在电机启动时可能会触发过电压错误。如果输入电压超过允许范围，请根据控制器输入电压和内部单相电压检查程序检查电压。

-> 伺服驱动单元输入电压规格：单相AC 220V

-> 电机启动时的允许范围：198V ~ 242V
